## ✦ Obsidian Demo Vault

> A preconfigured Obsidian vault designed to accompany the **YouTube tutorial**.

This repository contains the complete demonstration vault used throughout the tutorial. It includes the plugins, templates, visual systems, and folder configurations shown in the video, allowing you to explore the workflow without building everything from scratch.

## ◉ Better Graphs

**Better Graphs** is a plugin that I developed to provide more useful and advanced ways of visualizing knowledge inside Obsidian.

It expands the possibilities of the standard graph view and supports more intentional forms of:

* Knowledge visualization
* Note relationship analysis
* Advanced PKM workflows
* Visual exploration of large vaults
* Identification of patterns and connections

Rather than using the graph only as a decorative overview, Better Graphs is intended to make the graph more meaningful, readable, and useful for understanding your knowledge system.

## ⌘ Dataview

**Dataview** provides much of the underlying structure used throughout this vault.

It allows commands, queries, and scripts to run behind the scenes. These can automatically collect, organize, filter, and display information from different notes.

Within this vault, Dataview supports several dynamic elements and helps turn ordinary Markdown notes into a more structured knowledge system.

You do not need to understand every Dataview command immediately. Many of the required configurations are already included in the demonstration vault.

## ✐ Excalidraw

**Excalidraw** is used to create diagrams, sketches, visual notes, and hand-drawn-style illustrations directly inside Obsidian.

It can be used for:

* Concept diagrams
* Mind maps
* Research frameworks
* Visual explanations
* Process diagrams
* Hand-drawn annotations
* Spatial organization of ideas

Excalidraw is especially useful when an idea is easier to understand visually than through text alone.

## 🧭 Excalibrain and the Idea Compass

**Excalibrain** provides a visual way to explore relationships between notes.

In this vault, Excalibrain has been customized to work directly with the **Idea Compass** framework:

| Direction | Relationship  |
| --------- | ------------- |
| **North** | Mother idea   |
| **South** | Child idea    |
| **West**  | Friend idea   |
| **East**  | Opposing idea |

This configuration helps you examine an idea from several directions.

A mother idea represents a broader concept from which the current idea develops. A child idea represents a more specific idea that grows from the current note. A friend idea represents a related or supportive concept. An opposing idea represents a contrasting, contradictory, or challenging perspective.

> [!important]
> This Idea Compass configuration is a custom setup created specifically for this vault. Excalibrain does not include this exact configuration by default.

## ❖ Iconize

**Iconize** is installed to improve the visual organization of the vault.

The plugin includes access to several icon packs that can be used to customize folders, files, and other vault elements.

Icons can make a large vault easier to navigate by helping you identify different types of content at a glance.

In this vault, icons are used to create a more readable and visually organized folder structure.

## ⚙ Templater

**Templater** supports the creation of dynamic and reusable note templates.

Instead of manually recreating the same note structure, Templater can automatically insert information such as:

* Dates
* Titles
* Metadata
* Folder information
* Repeated headings
* Dynamic text
* Custom scripts

This is especially helpful for recurring notes, research notes, literature notes, project notes, and other structured PKM workflows.

Several templates are already included in the vault and can be adapted to your own system.

## 📚 Zotero Integration

**Zotero Integration** connects the Obsidian vault with your Zotero reference library.

For the integration to work correctly, you must also install **Better BibTeX for Zotero** inside Zotero.

The complete connection between Zotero and Obsidian can take some time to configure. However, this demonstration vault already includes a Zotero Integration template that has been designed for the workflow shown in the tutorial.

The basic process is:

```text
Zotero Library
      ↓
Better BibTeX
      ↓
Zotero Integration
      ↓
Obsidian Reference Note
      ↓
References Folder
```

When you import a source from Zotero, the available annotations, highlights, notes, and bibliographic information can be collected inside a structured reference note.

These imported notes are initially gathered in the **References** folder.

From there, you can:

* Keep them inside the References folder
* Move them into a research project
* Allocate them to a subject folder
* Connect them with permanent notes
* Link them to diagrams or Idea Compass relationships
* Organize them according to your preferred PKM system

> [!note]
> The Zotero template is already included in this vault, but Zotero, Better BibTeX, and the Zotero Integration plugin must still be properly connected on your computer.

## ⚠ Before Using the Vault

When you first open the vault, Obsidian may ask whether you trust the author and whether you want to enable community plugins.

Review the installed plugins and enable them only if you are comfortable using them.

Some features may not function until the related plugins are enabled and their required external applications are installed.

For Zotero-based features, make sure you have:

1. Zotero installed
2. Better BibTeX for Zotero installed
3. Zotero Integration enabled in Obsidian
4. The correct Zotero database and export settings configured
5. The included Zotero template selected inside the plugin settings
